# Regional expression of brain-disorder risk genes

**Question.** Are GWAS risk genes for brain disorders more strongly expressed in particular brain regions?

**Approach.** Regional gene expression from the Allen Human Brain Atlas (six donors, 83 Desikan-Killiany regions, processed with abagen) is combined with GWAS Catalog risk genes for 11 disorders and 2 non-brain controls. Each region is scored by the mean expression of a disease's risk genes and compared with 10,000 random gene sets. Matched nulls control for the dominant expression gradients (PC1, and PC1 x PC2). Statistics use 42 regions (left hemisphere plus brainstem) with FDR correction.

## Main results
- **Positive control works.** Striatal marker genes score highest in caudate (z = 7.3), putamen (5.5) and accumbens (2.9).
- **Schizophrenia, bipolar disorder and major depression** show broad enrichment (14-29 of 42 regions) that survives gradient-matched nulls. The signal is broad, so no region-specific targeting is claimed.
- **ADHD** is not robust to matched nulls. **Alzheimer's, Parkinson's, MS, ALS, epilepsy, migraine** and both negative controls (Crohn's, coronary artery disease) show no significant regions in any version.
- Standard random-gene nulls overstate regional specificity.

See `docs/notes.md` for every design decision and result, including exclusions (autism: 19 usable genes; Huntington's: 1 usable gene).

- `gene_lists/` - the exact gene lists used
- `figures/` - heatmaps, robustness, positive control, clustering
- `docs/notes.md` - design record and results log
- `analysis.ipynb` - the full analysis in one notebook (run top to bottom in Google Colab)
## Data
- Allen Human Brain Atlas microarray data via abagen 0.1.3
- GWAS Catalog `gwas-catalog-associations_ontology-annotated-full.zip` (downloaded 2 November 2026)
- Large files are not included: the expression table (`expression_dk.csv`) is regenerated by abagen, and the GWAS file is downloaded from the GWAS Catalog FTP.

## How to reproduce
Open `analysis.ipynb` in Google Colab and choose Runtime > Run all. It builds the expression table, gene lists, all null models and the figures. A full run takes roughly 1 to 3 hours; set `QUICK_TEST = True` at the top for a 10-minute test. abagen 0.1.3 is run in an isolated environment with pinned library versions (numpy 2.1.3, pandas 2.2.3, scipy 1.16.3, nibabel 5.4.2) plus small compatibility fixes, described in the notebook. Rerunning from scratch reproduced all 60 original result files exactly.

```python
# 1. patch (run after installing abagen, before importing it)
import glob, re
pkg = '/usr/local/lib/python3.13/dist-packages/abagen'
for f in glob.glob(pkg + '/**/*.py', recursive=True):
    t = open(f).read()
    new = re.sub(r'(set_axis\([^)]*?),\s*inplace=False\s*\)', r'\1)', t)
    if new != t:
        open(f, 'w').write(new)

# 2. shim (run in every session, before abagen.get_expression_data)
import pandas as pd
def _df_append(self, other, ignore_index=False, verify_integrity=False, sort=False):
    if isinstance(other, pd.Series):
        other = other.to_frame().T
    if isinstance(other, (list, tuple)):
        frames = [self] + [o.to_frame().T if isinstance(o, pd.Series) else o for o in other]
    else:
        frames = [self, other]
    return pd.concat(frames, ignore_index=ignore_index,
                     verify_integrity=verify_integrity, sort=sort)
pd.DataFrame.append = _df_append
```

Output of the patched abagen was not compared with an unpatched environment.
